1. 核心邏輯（他本人最精華的 6 點）
Lana 把整個系統定位為「抓主動 MM（莊家）打窩引魚」的輿情流向代理人，而不是傳統技術分析或鏈上跟聰明錢。

為什麼選 Binance Square？
他觀察到過去三個月很多 MM 都在找「幣安合約殼」，而 Square 是散戶最集中、不受牆影響的資訊源 → 類似鏈上抓資金流，但換成「抓輿情流」。MM 想拉盤一定會先在魚多的地方打窩。
抓取與過濾指標（最關鍵）：
監控 Square 每天帖子量最高的幣 + 流量最高的貼文。
粗暴 bot 過濾：改過名字 = 真人；沒改名 + 大量發帖 = bot（他自己說這方法很粗暴但有效）。
優先追高：只看漲幅榜上正在異動的標的（敢追高，因為 MM 不會只拉幾十點就跑）。
標的池偏好：過去半年剛上幣安的幣，或過去有過大幅波動的幣（流動性好、容易被炒熱）。
OI 異動過濾（他自己加的最佳化）：過去 48 小時持倉量（OI）大漲，但價格還沒明顯反應 → 資金已偷偷進場，價格還沒跟上。
額外投餵：即時新聞 + 蒸餾他自己的 X 風格 + 過去 onchain 錢包打法。

2. 運作流程（從 100U 到 4.8 萬 U 的實際執行）

起手：100U 本金 → 讓 Claude 寫腳本 → 自動刷 Square 熱帖 + 漲幅榜 → 自動開倉（只做一個方向）→ 掛止損。
止損演進：一開始 20% 止損 → 後來改成固定虧 200U 就止損（不管倉位多大，只虧固定金額）。
止盈：完全不設固定價位。每隔一段時間（他提到類似 Cron 任務）讓 AI 重新判斷「繼續上漲機率 > 下跌機率」才繼續持有；止盈時採小批次分批賣出（1%~5%），讓利潤奔跑。
曬單閉環：開倉同時自動在 Square 發文 + 截圖（有時還要他本人幫忙截手機圖，因為「散戶更相信手機截圖」）。
自我迭代：每天人機對話餵新資訊、調整 Prompt，讓 Agent 越來越像他本人思考。
技術底層：早期用 OpenClaw → 現在已轉純 Claude（他說 Claude 能做的事不需要再套一層）。

整個流程是執行 100% 自動 + 思考半自動（人類負責餵知識、邪修 Prompt）。
3. 優勢（為什麼這波能 480x）

中立性：AI 不會因為持倉而「屁股歪掉」，完全按 Prompt 執行。
速度：24 小時不睡覺監控 Square + OI，抓到熱度最早爆發的瞬間。
閉環放大：交易 + 曬單同時進行，形成正向循環（更多人看到 → 更多熱度 → 更多 OI → 價格更容易拉）。
低主觀干預：人類只負責「出奇招、邪修」，執行交給 AI，減少情緒干擾。
小資金起步優勢：第一筆就抓到大行情，快速累積本金（他自己說這是 90% 運氣）。

4. 風險與弱點（他本人也多次提醒）

極度依賴特定行情：他自己說「我這波是運氣佔 90%，第一筆交易就打下資金墊，換一個行情應該就失效了」。這套策略在本質上是追右側熱度 + 低流動性市場追高，在熊市或沒 MM 打窩的時候會連續止損。
bot 與噪音：Square bot 很多，他的過濾方法很粗暴，未來 bot 進化後可能失效。
蒸餾偏差：餵自己的舊貼文/錢包歷史，會讓 AI 產生「歷史偏差」（例如因為 CZ 轉發的舊貼而選錯幣）。
反爬與風控：抓 Square 本身沒官方 API，依賴 browser automation，容易被 Binance 限流或風控。
固定金額止損的兩面刃：小倉位時很安全，但本金變大後，200U 止損其實變得「太寬鬆」，可能一次大回撤就吃掉很多利潤。
不是穩定印鈔機：他反覆強調「AI 是工具，要出奇招、邪修才有機會」，不是量化穩定策略。
