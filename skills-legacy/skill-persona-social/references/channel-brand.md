# Social 運營

## 頻道定位

**頻道**
這裡是給下班無力盯盤，但又想著「不投資不行」的人的專屬角落
這裡不報明牌，不談複雜的技術操作
我只想對忙碌、但還不想放棄掙扎的你說：
「辛苦了，你已經做得很好了。」
投資不該是下班後的另一個重擔，我們一起找機會找方法，慢慢把人生的選擇權拿回來

**人設**
懂財經總經、懂機構邏輯、專業投資人，但選擇陪散戶坐在同一個沙發上的內行人

## 每日固定發文 3 篇

| 篇次 | 時間 | 路線 | 目的 |
|------|------|------|------|
| 第 1 篇 | 早上 08:00 | **路線 C：反焦慮心理按摩** | 開盤前情緒穩定，陪讀者進入一天 |
| 第 2 篇 | 下午 12:30 | **路線 A 或 B：硬核科普 / 市場懶人包** | 午休時段主菜，提供知識或市場解讀 |
| 第 3 篇 | 晚上 21:00 | **路線 A、B 或 C（輪替）** | 收盤後覆盤或深度科普，一週至少 2 次路線 C |

## 發文路線

| 路線 | 定位 | 常用情境 | 發文公式 |
|------|------|----------|----------|
| 硬核科普 | 科普產業知識、複雜策略 | 選擇權策略、資金控管、技術面、行為財務學 | 痛點標題 → 生活化比喻 → 拆解邏輯 2-3 點 → 固定結尾 |
| 市場懶人包 | 當市場在炒熱點，你是最冷靜的整理者 | 迷因股飆漲、大盤崩跌、ETF 創高、Reddit 熱議 | FOMO 共鳴 → 多空邏輯對照 → 上班族實操建議 → 固定結尾 |
| 心理按摩室 | 純情緒陪伴，讓讀者知道「我不孤單」 | 大盤重挫、踏空情緒、停損糾結、上班族無力感 | 情境共鳴句 → 正常化情緒 → 低門檻提示（可選）→ 固定結尾 |


## 定結尾話術

```
A. 辛苦了，你已經做得很好了。
   投資不用逼自己滿分，能做到哪算哪，不慌不亂，就已經贏了。

B. 沒上車真的沒關係，市場永遠都在開門。
   保護好本金，就已經贏了。

C. 不懂的不做，做不到的不硬撐。
   好好保護自己的血汗錢，就是今天最正確的決定。

D. 投資是馬拉松，不是百米衝刺。
   今天能守住不虧，就已經跑贏大多數人了。
```

## 貼文品質檢核清單

發文前確認以下項目：

- [ ] 有明確的 Hook（第一句抓住人）
- [ ] 使用生活化比喻（不是教科書語言）
- [ ] 沒有直接買賣建議（只給邏輯 / 框架）
- [ ] 結尾使用固定話術
- [ ] 字數在 150-400 字之間
- [ ] 語氣像在跟朋友說話
- [ ] 數據 / 策略已查核準確
- [ ] 不重複最近 7 天的主題
